# 图标来源与许可证

所有文件均为对应仓库的**原始 SVG**（未改路径、未改 stroke-width），仅做 viewBox 缩放。

| 库 | 许可证（以仓库 LICENSE 为准） | 文件 | 上游路径 |
|---|---|---|---|
| Lucide | **ISC** | `lucide/rabbit.svg` `lucide/play.svg` `lucide/package.svg` | `lucide-icons/lucide@main/icons/<name>.svg` |
| Phosphor | MIT | `phosphor/rabbit-regular.svg` `phosphor/rabbit-fill.svg` `phosphor/play-regular.svg` `phosphor/package-regular.svg` | `phosphor-icons/core@main/assets/{regular,fill}/<name>.svg` |
| Tabler | MIT | `tabler/player-play.svg` `tabler/package.svg` | `tabler/tabler-icons@main/icons/outline/<name>.svg`（该库**没有 rabbit / play**） |
| Remix Icon | **Remix Icon License v1.0（自定义，禁止 logo 用途）** | `remix/play-circle-line.svg` `remix/play-line.svg` `remix/play-fill.svg` | `Remix-Design/RemixIcon@master/icons/Media/<name>.svg`（该库**没有 rabbit**） |

## ⛔ 关于 Remix Icon

`icons/remix/LICENSE.txt` 是 Remix Icon License v1.0（Version 1.0 – January 2026），其中：

> 3.3 Prohibited: Logo, Trademark, and Brand Identity Use — You may NOT use the Icons, whether modified or unmodified, as a logo, trademark, or brand identifier.

因此 **Remix 图标不能用于本项目的 logo**。目录里保留 Remix 文件只作对照与留档，**不要**把它用到任何品牌位。
（任务书假设 Remix 为 MIT / Apache-2.0，与仓库实际不符，已在此更正。）

## 用在产品里的义务

- Lucide (ISC) / Phosphor (MIT) / Tabler (MIT) 均为宽松许可：可商用、可修改、可作 logo，但**必须保留版权与许可文本**。
- 各库 `LICENSE.txt` 已随目录保存，发版时随第三方声明一同分发即可。
