# QTools 用户端改版方案（v2）

> 目标：把现在「一站点四套外壳」的用户端，收敛成一套外壳 + 四类页面模板。
> 参考视觉：30aitool.com（左侧可折叠导航 + 内容区 + 细描边卡片）。
> 本文是实现与验收的共同依据；改动以本文为准，本文随实现同步更新。

---

## 1. 现状诊断（改版要解决的问题）

| 页面 | 改版前的外壳 | 宽度基准 |
| :--- | :--- | :--- |
| 首页 `/` | `AppHeader` + `AppFooter` | 1200px 居中 |
| 登录 / 注册 / 账号 | `AppHeader` | 1200px 居中 |
| 媒体站三页 | `AppHeader` + 额外一条 sticky 横向导航 | 全屏 |
| 视频库 `/media` | 上面那套 **再加** 自带 240px `fixed` 左栏 | 全屏 |
| 工具页 ×3 | **没有任何 header**，只有 `qt-container` | 1200px 居中 |

同一个站点里 4 种骨架、2 种宽度基准、2 种导航语言 —— 这是"不一致""遮挡""很怪"的根因。

## 2. 设计原则

1. **一个外壳**：全站只有一套导航骨架（`src/layouts/AppShell.vue`），页面只填内容区。
2. **内容优先**：工具页/媒体页不做营销式头部，只保留"我在哪 + 我能做什么"。
3. **一套尺度**：间距/圆角/字号/描边收敛成 `--qt-*` 令牌，页面禁止硬编码颜色。

## 3. 外壳规范（AppShell）

### 3.1 结构

```
┌ 左栏（200px / 收起 56px）┬ 内容区（全宽，桌面 padding 28px） ┐
│ Logo / 站点名（→ /）      │                                 │
│                           │                                 │
│ 工具                      │                                 │
│  ▎首页    /               │        <router-view />          │
│   全部工具 /#tools        │                                 │
│ 媒体                      │                                 │
│   视频库  /media          │                                 │
│   图片站  /media/photos   │                                 │
│                           │                                 │
│ （弹性空白）               │                                 │
│ 🌙 主题切换  👤 个人中心   │                                 │
└───────────────────────────┴─────────────────────────────────┘
```

- **个人中心固定在左栏底部**（不在"媒体"分组里）；未登录时该位置显示「登录」。
- 分组标题为小号灰字，收起态隐藏。
- 选中态：左侧 3px 竖条 + 强调色文字 + 浅底。

### 3.2 折叠手柄（复刻 30aitool）

- 鼠标进入左栏区域时，在左栏**右边缘**浮现 28px 圆形按钮（展开态 `‹`、收起态 `›`）。
- 按钮**纵向位置跟随鼠标 Y**（clamp 在栏内，上下各留 40px），`requestAnimationFrame` 节流。
- 鼠标离开 300ms 后淡出（`opacity` 过渡 + `pointer-events: none`）。
- 点击切换折叠；状态持久化在 `localStorage['qtools-rail-collapsed']`。
- 内容区 `margin-left: var(--qt-rail-w)`，宽度变化 `transition: .18s`。
- 无障碍：`<button>` + `aria-expanded` + `aria-label="收起导航/展开导航"` + `aria-controls`。

### 3.3 响应式

| 断点 | 行为 |
| :--- | :--- |
| ≥1024px | 左栏常驻（200/56 可折叠） |
| <1024px | 左栏隐藏 → 顶部紧凑条（`☰ 站点名 … 主题切换`）；`☰` 打开全高抽屉（遮罩、ESC 关闭、锁定 body 滚动） |

**不做底部 tabbar**（用户明确要求）。

## 4. 页面模板

### T1 首页（`/`）
1. **Hero 营销位**：纯文字 + 浅底细线框（不用大图/渐变）。站点名 + 一句话定位 + 三个特性徽标（纯本地运算 / 免注册即用 / 数据不上传）+ 主按钮「开始使用 ↓」（滚到 `#tools`）与次按钮「媒体站 →」。
2. **使用指引（3 步）**：选工具 → 粘贴/上传 → 直接拿结果（不经过服务器）。
3. **工具索引**：搜索 pill + 分类 chips（全部/文本/编码/生成/安全/媒体）+ 最近使用（`localStorage['qtools:recent-tools']`，最多 6）+ 工具卡片网格（图标 + 名称 + 两行描述 + 「本地运算」徽标）。
4. 底部一行说明：所有工具在浏览器本地运行，不上传数据。

### T2 工具页（`/tool/*`）
面包屑 → 标题 + 「数据不上传」徽标 → 操作条 → 输入区 / 结果区 → 说明折叠。
（P3 抽 `ToolLayout` 统一）

### T3 媒体页（`/media`、`/media/photos`）
内容区顶部：搜索 pill + 排序 + `筛选` 按钮 + 计数；最近观看条；卡片墙（分块渲染 + 懒加载）。
**筛选改为右侧抽屉（320px）**，左栏只放导航 —— 这是消除"遮挡左栏"的关键。

### T4 个人中心（`/me`）
① 身份卡（头像可编辑 + 昵称 + @用户名；未登录显示登录引导）→ ② 收藏 → ③ 最近浏览 → ④ 基本资料 → ⑤ 登录方式（邮箱/手机号「未开放」置灰）→ ⑥ 认领本设备媒体数据 · 退出登录。

- 媒体身份是 `ms.owner`（与站级登录无关）：未登录也能看本机媒体的收藏/最近。
- `/media/me`、`/account` 保留为 **redirect 到 `/me`**，旧书签不失效。

## 5. 设计令牌（`src/styles/variables.scss`）

| 类别 | 令牌 | 说明 |
| :--- | :--- | :--- |
| 背景 | `--qt-bg-page` `-card` `-hover` `-elevated` | elevated 用于浮层/弹窗 |
| 描边 | `--qt-border` `-strong` | 细描边替代重阴影 |
| 文字 | `--qt-text-primary` `-secondary` `-tertiary` | 三级文字阶梯 |
| 强调 | `--qt-primary` `-hover` `-on-primary` | 实心按钮底色需压深到与 `-on-primary` ≥ 4.5:1 |
| 圆角 | `--qt-radius-sm/md/lg` | 6 / 10 / 14 px |
| 间距 | `--qt-space-1…6` | 4 8 12 16 24 32 px |
| 阴影 | `--qt-shadow-card` `-pop` | 卡片极轻、浮层明显 |
| 布局 | `--qt-rail-w` `--qt-shell-pad` | 176/56px（P5.40 由 200px 收窄）、桌面 28 / 移动 16 |

## 6. 实施分期与验收

| 期 | 内容 | 验收 |
| :--- | :--- | :--- |
| **P1 外壳** | `AppShell.vue`（折叠手柄 + 移动抽屉 + 令牌）；六类页面接入；删除 `AppHeader` 与媒体站横导航 | 全站导航一致；无第二套 header；亮暗正常；手柄跟随鼠标 |
| **P2 首页** | Hero + 3 步指引 + 搜索/分类/最近使用 + 卡片网格 | 首屏可直接搜索；卡片视觉统一 |
| **P3 工具页** | 抽 `ToolLayout` ×3 | 三页骨架一致，仅内容不同 |
| **P4 媒体页** | 视频库左栏 → 右侧筛选抽屉；最近条与卡片视觉对齐 | 不再遮挡左栏；内容区全宽 |
| **P5 个人中心** | `/me` 合并；登录/注册页套壳 | 一个入口一个页面；旧路由重定向有效 |

## 7. 已确认的决策

1. 个人中心**合并为一个 `/me`**（头像昵称 + 收藏 + 最近浏览 + 账号资料 + 退出登录），`/media/me` 与 `/account` 重定向到它。
2. 左栏宽度**展开 200px / 收起 56px**。
3. 首页 Hero **纯文字 + 特性徽标 + 两个按钮**，不使用大图或渐变背景。
4. 手机端**不做底部 tabbar**，用顶部紧凑条 + 抽屉。

## 8. 风险与回滚

- 路由**路径不变**（只换外壳与页面结构），旧 URL、书签、`tool_info.tool_route` 全部有效。
- 旧手写静态页 `/media/*.html` 仍保留，可作媒体站回滚通道。
- 媒体站自带 240px 左栏在 P4 移除前会与新外壳争夺横向空间，属迁移期已知问题。
