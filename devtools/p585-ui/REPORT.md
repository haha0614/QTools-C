## 1. 三层结构 + 柔光（最终形态）

```
.pw-card  (--pw-blur-fade-end: 78%; --pw-img-fade: linear-gradient(to right, rgba(0,0,0,0) 0%, rgba(0,0,0,.45) 9%, #000 20%))
├── span.pw-glow                ← 层 0 柔光（垫底，在拾色底之上、图片之下）
└── span.pw-bg  (inset: 0; z-index: 0; overflow: hidden)
    ├── img.pw-bg-sharp  层 1 清晰原图        filter: none
    │                        mask: var(--pw-img-fade)
    ├── img.pw-bg-blur   层 2 blur(半径)       filter: blur(var(--pw-bg-blur)) saturate(1.1) brightness(.9)
    │                        mask: <缓动 6 停靠点> , var(--pw-img-fade)   mask-composite: intersect
    └── img.pw-bg-fog    层 3 blur(半径 × 2.6) filter: blur(calc(var(--pw-bg-blur) * 2.6))
                             mask: linear-gradient(to right, #000 0%, transparent 52%) , var(--pw-img-fade)   mask-composite: intersect
```

三层的 src / currentSrc **完全一致**（A4），同一 URL 浏览器只发 **1 个请求**（A9：19 个图片请求，0 个重复）。

### 1.1 各层 computed mask（实测，D 段）

| 层 | computed mask-image（第 1 层） | 第 2 层 | composite |
|---|---|---|---|
| 层 2 blur | `linear-gradient(to right, rgb(0,0,0) 0%, rgba(0,0,0,.92) 18%, rgba(0,0,0,.62) 34%, rgba(0,0,0,.3) 50%, rgba(0,0,0,.08) 64%, rgba(0,0,0,0) 78%)` | `var(--pw-img-fade)` | `intersect` |
| 层 3 fog | `linear-gradient(to right, rgb(0,0,0) 0%, rgba(0,0,0,0) 52%)` | `var(--pw-img-fade)` | `intersect` |
| 层 1 sharp | `linear-gradient(to right, rgba(0,0,0,0) 0%, rgba(0,0,0,.45) 9%, rgb(0,0,0) 20%)` | — | — |

- **渐变端点**：`--pw-blur-fade-end` = **78%**（D5，声明在 `.pw-card` 上，变量保留），
  停靠点 alpha = 1 / .92 / .62 / .3 / .08 / 0（D3）。
  相邻停靠点的 alpha 斜率 = 0 / 0.02 / 0.02 / 0.02 / 0.01（每 1% 卡宽），
  旧版 `45% → 70%` 直线是 **0.04**（D6）——斜率减半且分段，肉眼没有「斜切」感。
- 13 张卡的 mask 逐字一致，不随卡片宽度变化（D1）。

### 1.2 左侧柔光（层 0）

```css
.pw-glow { position: absolute; inset: 0; opacity: .35;
  background: radial-gradient(145% 165% at 0% 50%,
    color-mix(in srgb, var(--pw-tone, var(--bg-2)) 70%, #fff) 0%,
    color-mix(in srgb, var(--pw-tone, var(--bg-2)) 70%, #fff) 26%,
    transparent 70%); }
.dark .pw-glow { /* 同一形状，混合色换成压暗版 #0b0d10 */ }
```

实测 computed：`radial-gradient(145% 165% at 0% 50%, color(srgb 0.829804 0.824314 0.813333) 0%, … , rgba(0,0,0,0) 70%)`
（color-mix 已由浏览器解析成具体颜色，F5）；`opacity: 0.35`（F2，封顶值）；
自身 `background-color: rgba(0,0,0,0)`（F4）；**卡片内纯白 / 纯黑不透明遮罩块 = 0 个**（F6）。
柔光在**右侧收到完全透明**（F3），所以不压右半的清晰照片。

## 4. 接缝探针：图片左边界那条硬竖线（本轮真正的发现）

**问题**：`imgW = bgW × 0.44 / cropW`（不放大），当 `cropW > 0.44` 时图片**比卡片窄**，
它的左边界在卡片内部就是一条**硬直竖线**（卡 125 上位于卡内 **129px**）。
这条线在元素盒子内部，**mask 停靠点再怎么缓动都碰不到它** —— P5.84 的截图里 13 张卡有多张能看到这条线。

**修法**：每层都先按**图片自身宽度**做一次左缘渐显 `--pw-img-fade`
（`transparent 0% → .45 9% → #000 20%`），模糊层 / 雾层再用 `mask-composite: intersect`
与自己那条横向停靠点渐变取交集 —— **停靠点数值一个字没改**，只把接缝化开。

实测（卡 125，采样列 = 图片左缘 −30…+40px，纵向取卡片中段 80 行平均）：

```
新版剖面（相邻像素最大跳变 1.98 / 255）：198 197 198 197 … 197 197 198 198 199 200 201 202 203 204 205 206 207 208 210 212 213 214 215 216 217
旧版剖面（相邻像素最大跳变 6.15 / 255）：198 197 … 197 198 197 197 197【203 198 197 195 194 192 190 189 188 187】187 188 189 190 192 194 197 200 203
```

旧版在 x = 129px（图片左缘）处一步掉 6.15 / 255 再慢慢爬回来 = 那条竖线；
新版最大跳变只有 **1.98 / 255（≈0.8% 亮度）**，剖面是连续上升 —— 肉眼分不出边界。

## 6. 与任务书的差异（需要交代的三点）

1. **新增了「图片自身左缘渐显」**（`--pw-img-fade` + `mask-composite: intersect`）。
   任务书只给了 mask 停靠点 + 三层 + 柔光；但几何上图片可能比卡片窄，它的左边界在元素内部，
   停靠点改不动那条硬线（§4 有实测剖面）。这一层是**为了让「看不出分界线」这条验收真正成立**而加的，
   且**没有改动任务书给的任何停靠点数值**。支持性：Chrome `mask-composite` 已实测生效（D8 读到 `intersect, intersect`）。
2. **`.pw-glow` 是卡片的直接子节点**（`.pw-bg` 的兄弟），不是 `.pw-bg` 的孩子。
   位置上仍是「拾色底之上、图片之下」（DOM 顺序 + 都是 z-index: 0 的定位元素，A5 断言层序）；
   放在外面是为了让任何将来加在 `.pw-bg` 上的 mask 不会把柔光一起吃掉。
3. **`--pw-blur-fade-end` 从「只写在 var() 回退值里」改成声明在 `.pw-card` 上并保留回退值**，
   这样它可以被 computed style 读到（验收要求「`--pw-blur-fade-end` = 78%」）。
   另外：mask 的百分比基准是**图片盒子宽度**（不是卡片宽度，P5.84 就是如此），
   所以「卡内哪个 x 是 78%」会随每张卡的 `cropW` 变化 —— 这是已知特性，本版未改。

## 7. 已知限制

- **过渡位置随裁剪比变化**：mask 百分比相对图片宽度，`cropW` 大的卡（图片窄）过渡带在卡片坐标里更靠右；
  极端情况下（图片只占卡片右半）左侧几乎整片是「拾色底 + 柔光」的纯色渐变，照片只在右半出现 —— 与参考图二一致，但卡与卡之间"开始看清"的 x 位置不统一。
- **左端颜色取决于拾色**：柔光用的是 `--pw-tone`（personTone 从同一张图采样得到的落地色）的亮化版，
  所以「淡粉」还是「淡灰」由照片本身决定；采样未回来 / 失败的卡（`.has-tone` 不存在）退回 `--bg-2`，左端会偏中性。
- **极窄卡片**（< 240px，目前 375 档是 335px，不触发）时三层的 mask 百分比更贴近，过渡带视觉上更短。
- 三层都带 `filter: blur()`，滑块 20px 时层 3 是 52px 高斯 —— 卡片尺寸下的合成成本仍是一次性的（只在静态绘制时算），
  实测整轮 18 次开页 0 console error、无掉帧相关告警。
- 对比度仍不做任何保证（用户口径：文字直接压图，看不清再说）；实测最低 1.04:1 仅作记录。
